# 261125 — 철도 차량 정비 지식 플랫폼 (가칭)

과거 고장 조치 보고서를 부서·차량·부품별로 모아 보고, AI로 유사 사례 검색과 보고서 초안 작성을 돕는 웹 서비스입니다. 모든 데이터는 가상 데이터입니다.

## 개발 스택
| 구분 | 선택 |
| --- | --- |
| 프레임워크 | Next.js 16 (App Router) + TypeScript |
| UI | Tailwind CSS + shadcn/ui, 차트: Recharts |
| DB·인증·파일 | Supabase (PostgreSQL, Auth, Storage, pgvector) |
| 생성형 AI | Google Gemini API 무료 등급 (gemini-3.5-flash, gemini-3.1-flash-lite) |
| 임베딩 | Gemini Embedding (gemini-embedding-2, 같은 키) |
| 배포 | GitHub → Vercel 자동 배포, Supabase Cloud |

## 설치해야 할 것 (Windows)
1. Node.js 24 LTS — `node -v` 로 확인
2. Git — `git --version` 으로 확인
3. VS Code
4. Supabase CLI (선택) — `npx supabase --version`

## 프로젝트 생성 (개발 시작 시)
```bash
cd %USERPROFILE%\Desktop\261125
npx create-next-app@latest . --ts --tailwind --eslint --app --src-dir --import-alias "@/*"
npm install @supabase/supabase-js @supabase/ssr @google/genai recharts
npx shadcn@latest init
```

## 배포 흐름
1. 코드를 GitHub `main` 브랜치에 push
2. Vercel에서 저장소 Import → 환경 변수 입력 → Deploy
3. 이후 push 할 때마다 자동 배포
